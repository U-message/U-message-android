nudenet_320n.tflite
===================

Source: notAI-tech/NudeNet 3.4.2 (detector "320n.onnx", a YOLOv8n model) - https://github.com/notAI-tech/NudeNet
Modification: input fixed to 1x3x320x320 and the graph cut before box decoding, so it only outputs the
              per-anchor class scores; converted to TensorFlow Lite (onnx2tf) with float16 weights.

Input : float32 [1,320,320,3], RGB 0..1; the picture padded with black at the right/bottom to a square, then
        resized to 320x320
Output: float32 [1,18,2100] sigmoid class scores per anchor. Classes: FEMALE_GENITALIA_COVERED, FACE_FEMALE,
        BUTTOCKS_EXPOSED, FEMALE_BREAST_EXPOSED, FEMALE_GENITALIA_EXPOSED, MALE_BREAST_EXPOSED, ANUS_EXPOSED,
        FEET_EXPOSED, BELLY_COVERED, FEET_COVERED, ARMPITS_COVERED, ARMPITS_EXPOSED, FACE_MALE, BELLY_EXPOSED,
        MALE_GENITALIA_EXPOSED, ANUS_COVERED, FEMALE_BREAST_COVERED, BUTTOCKS_COVERED
